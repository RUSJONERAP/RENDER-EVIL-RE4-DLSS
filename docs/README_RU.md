# RE:NDER EVIL — умный установщик 0.2.0 preview.1

Один автономный установщик для DLSS SR, независимого NR и опциональной генерации кадров в Resident Evil 4 Remake. Поддерживается Steam-версия 1.5.9.0 с проверкой хеша EXE. Все runtime-зависимости уже внутри архива; отдельно скачивать моды не нужно.

## Установка

Распакуйте весь ZIP вне папки игры. Закройте RE4, запустите **Install.cmd**, выберите язык RU/EN и проверьте найденную папку игры и видеокарту. Нажмите **Проверить**, затем **Установить**. На компьютере с несколькими GPU выберите RTX, на которой запускается игра.

| Профиль | Поведение |
| --- | --- |
| Автоматически | Штатный FG для распознанных RTX 40/50, если HAGS явно не отключён. На других/неопределённых GPU — без FG. |
| Без FG | SR/NR-связка; библиотеки генерации и адаптер старых карт не устанавливаются. |
| Штатный FG | Streamline для RTX 40/50. По умолчанию 2× и Reflex On. |
| Эксперимент RTX 20/30 | Streamline и dlssg_for_sm86 0.4.1 с его готовым winmm.dll. Нужен драйвер R580+ и явное согласие на эксперимент. В нашей полной связке на этих GPU пока не проверен. |

Адаптер работает только как FG-провайдер. Его ускорение SR INT8 и XeSS отключены; лишние библиотеки не устанавливаются. Наша version.dll от F5 сохраняется. Одновременная установка нескольких адаптеров не предусмотрена.

Состояние HAGS проверяется без изменения Windows. Отсутствующий ключ реестра означает «не определено», а не «выключено». Если HAGS явно выключен, FG-профиль заблокирован; установка без FG доступна. Профили NVIDIA, глобальные лимиты FPS и настройки Windows установщик не меняет.

NR устанавливается при любом выборе. Параметр «Neural Rendering при запуске игры» задаёт только его состояние при следующем запуске после установки: включён или выключен. «Не менять» сохраняет прежнюю настройку; если ставите впервые, NR будет выключен. После кнопки «Проверить» итоговое состояние написано явно. В самой игре NR всегда можно включить и выключить через Insert. Модель и интенсивность NR, язык, качество SR и пользовательские настройки сохраняются. При установке FG наш лимитер выключается, чтобы не мешать Streamline.

## В игре

**FSR 2 — ВКЛ., FSR 1 — ВЫКЛ.** Actual DLSS заменяет штатный проход апскейлера. **Insert** открывает общую панель: DLAA / Quality / Balanced / Performance, отдельные NR и FG. Множитель FG меняется в игре; включение/отключение загрузки FG требует перезапуска. Начните с 2×. Максимальный доступный множитель берётся из runtime.

Перед тестом FG закройте RTSS/MSI Afterburner — это требование Actual DLSS. Глобальный лимит драйвера может ограничивать отображаемый FPS при любом множителе. Выходить пока рекомендуется через меню; у прежней SR/NR-сборки была ошибка завершения через Alt+F4, отдельный тест выхода новой FG-связки ещё не завершён.

## Резервная копия и удаление

До изменений проверяются хеши игры и компонентов, конфликтующие DLL, информация о драйвере/HAGS и свободное место на диске игры. Каждый затрагиваемый файл сохраняется вне игры: **LocalAppData/RENDER-EVIL/SmartInstaller/Backups**. Неизвестные прокси не перезаписываются. Старые авторские/HUDLab Lua-панели архивируются, чтобы не спорить с нашей панелью. Сохранения и посторонние файлы не затрагиваются.

Для отмены закройте игру и запустите **Uninstall.cmd**. Восстановится непосредственно предыдущее состояние. Смену профиля можно установить новой транзакцией и отменять в обратном порядке. Файл `reframework/data/re4unified/installation.json` содержит путь к соответствующему резервному манифесту.

Командная строка: `Install.ps1 -GameDirectory "D:\...\RE4" -Mode auto -CheckOnly`. Режимы: `auto`, `off`, `native`, `legacy`. Для legacy требуется `-AcknowledgeExperimental`; `-GpuIndex` выбирает найденный GPU. `-NrMode preserve|on|off` управляет NR. Без `-CheckOnly` начинается установка. `Uninstall.ps1 -Manifest "...\installed.json"` восстанавливает выбранную транзакцию.

## Статус сборки

Внутри: Actual DLSS 0.3.1, Streamline 2.14.16, SR/NR/FG runtime 310.9.16.0, оригинальный F5 beta.6, опциональный sm86 0.4.1. Подписи NVIDIA штатных SR и FG проверены; предоставленный NR runtime не подписан, его подлинность подписью NVIDIA не подтверждается. Хеши — в `catalog.json` и `SHA256SUMS.txt`.

В нашей проверенной сессии RTX 5070 Ti работали SR + NR + FG 2×; генерация 3× также зафиксирована. RTX 40 и полная связка на RTX 20/30 остаются непроверенными на соответствующих картах. Это предварительная сборка; RC.2 сохранена отдельным релизом. На Nexus первая загрузка находится в карантине. Подробнее об обнаружениях: [SECURITY_STATUS.md](SECURITY_STATUS.md).

Авторы сборки и интеграции: RUSJONERAP + Codex. Actual DLSS — khanguyen111; спасибо за разрешение на публикацию на Nexus. Остальные авторы, исходники и лицензии сохранены в комплекте.
