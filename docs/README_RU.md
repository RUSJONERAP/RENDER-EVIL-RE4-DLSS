# RE:NDER EVIL (DLSS SR/NR) — 0.1.0 RC.2

Сборка и интеграция: **RUSJONERAP + Codex**.

Единая панель на **Insert**, русский и английский язык, NVIDIA DLSS Super Resolution и независимое DLSS Neural Rendering. Качество DLSS: DLAA / Quality / Balanced / Performance / Ultra Performance. Отдельный ограничитель FPS: 10–360, включая 72 / 90 / 100, с графиком времени кадра.

**В графике игры FSR 2 должен быть ВКЛЮЧЁН, FSR 1 — ВЫКЛЮЧЕН.** Actual DLSS заменяет проход FSR 2 на DLSS до отрисовки интерфейса и постобработки. Режим качества выбирается в нашей панели. Для собственного ограничителя FPS в игре нужна «Переменная» частота кадров.

## Установка и откат

1. Закройте игру. Распакуйте архив в отдельную папку, не прямо в игру.
2. Запустите `Install.cmd` и укажите каталог с `re4.exe`; либо выполните `Install.ps1 -GameDirectory "D:\Steam\steamapps\common\RESIDENT EVIL 4  BIOHAZARD RE4"` из PowerShell.
3. Установщик проверяет хеши, поддерживаемую версию игры и известные конфликты. Не смешивайте сборку с PD Upscaler, другим OptiScaler или ReShade/DXGI-инжектором.
4. Резервная копия сохраняется вне игры, в `%LOCALAPPDATA%\RENDER-EVIL\Backups`. Установщик печатает полный путь к `installed.json` — сохраните его.
5. Для отката при закрытой игре запустите `Uninstall.cmd` и укажите этот манифест. Текущие пользовательские настройки перед откатом тоже сохраняются. Сохранения и `re4.exe` не изменяются.

В чистом профиле NR изначально выключен: сначала убедитесь в работе SR, затем включите NR в Insert → «Нейрорендеринг». Существующие настройки NR сохраняются. Для RTX 5070 Ti / 1440p ориентир качества: Quality, NR B, 100%, один проход, после SR. Ограничитель FPS изначально выключен; выбирайте цель ниже устойчивой производительности сцены.

## Что проверено и что ещё проверяется

Проверенная конфигурация: RE4 Steam 1.5.9.0, Windows 11, RTX 5070 Ti, драйвер 621.01, 2560×1440. Установщик принимает только хеш исполняемого файла, указанный в `manifest.json`; совместимость с другими сборками не обещается.

В предыдущей ревизии после исправления времени жизни GPU-ресурсов проверены игровой процесс с SR+NR и читаемость интерфейса: повреждений текста и сбоев в проверенном сеансе не обнаружено. Лог зафиксировал более 115 тысяч завершённых кадров NR без ошибок модели. Подтверждены загрузка обеих runtime DLL и переключение SR, включая DLAA, Quality и Balanced.

В RC.1 переработана панель, добавлен ограничитель FPS и реализован обход NR для вспомогательных видов катсцен при сохранении SR. Пройдены тесты публичного NGX ABI, восстановления выключателя NR, GPU-fence и реального таймера (цель 90 FPS, измерено около 90 FPS). Срабатывание обхода вспомогательного вида в реальной катсцене пока не зафиксировано.

**Проверенные сценарии RC.1:** игровой процесс с SR+NR, меню и HUD, катсцена DLC, ограничение частоты до 70 FPS и выход через меню игры. В проверенных сценах интерфейс оставался читаемым, катсцена воспроизводилась плавно, а при включённом ограничителе в логе зафиксировано 69–70 FPS. Последний сеанс: 28 943 кадра NR без ошибок модели. Обычный выход через меню прошёл без ошибки.

**Известный дефект:** при Alt+F4 остаётся Fatal D3D error 4 / E_ACCESSDENIED (0x80070005). В записанном сеансе ошибка ResizeBuffers появилась после исчезновения окна игры. Пока выходите через меню игры. Точная причина и исправление Alt+F4 не подтверждены. Все катсцены основной кампании не проверены. Статус RC не означает финальный стабильный релиз. Генерация кадров выключена и не предлагается.

RC.2 меняет название проекта и упрощает установку, сохраняя путь рендера RC.1. Игровые проверки выполнены на RC.1; обновлённая панель и установщик прошли отдельные проверки без запуска игры.

## Распространение

Этот полный архив включает предоставленную пользователем DLL Actual DLSS. Её исходная страница ограничивает перезалив и модификацию; включение в сборку не меняет эти условия и не присваивает её авторство авторам интеграции. Компоненты имеют отдельные лицензии; общая лицензия не распространяется автоматически на сторонние DLL. Условия и авторство каждого компонента сохраняются при включении в комплект.

Для GitHub подготовлены исходники и `GITHUB_RELEASE_DRAFT.md`. Учитывайте известные ограничения сборки и условия каждого включённого компонента.
